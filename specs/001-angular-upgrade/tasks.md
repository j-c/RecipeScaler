## Dependencies & Execution Order

### Phase Dependencies

- **Setup (Phase 1)**: No dependencies — start immediately
- **Foundational (Phase 2)**: Depends on Setup completion — BLOCKS all user stories
- **US1 (Phase 3)**: Depends on Foundational — core MVP increment
- **US2 (Phase 4)**: Depends on US1 — build verification meaningful only after code is ported
- **US3 (Phase 5)**: Depends on US1 and US2 — tests require working, building components
- **Polish (Phase 6)**: Depends on all user stories being complete

### User Story Dependencies

- **User Story 1 (P1)**: Can start after Foundational (Phase 2) — no dependencies on other stories
- **User Story 2 (P2)**: Depends on US1 — the build is only meaningful once recipe code is ported
- **User Story 3 (P3)**: Depends on US1 and US2 — tests require ported standalone components and a working build

### Within Each User Story

- Component TypeScript before template (imports determine what directives/components are available)
- Template before end-to-end verification
- Styles can be parallel with template (different file)
- Verification/manual-test task always last in the phase

### Parallel Opportunities

- **Phase 2**: T004 + T005 + T006 (deletions), T007 + T008 (copies), T012 + T013 (theme files) — three parallel batches
- **Phase 3**: T017 (styles) can run in parallel with T016 (template)
- **Phase 5**: T022 + T023 (spec files) can run in parallel
- **Phase 6**: T025 + T026 (Playwright config + test) can run in parallel

## Notes

- Models and viewmodels require ZERO changes — pure TypeScript with no Angular dependencies
- The recipe template (~130 lines) is the largest porting task: Bootstrap HTML → Angular Material components
- All custom CSS removed — use Angular Material defaults only; custom styling is deferred to a future feature
- URL contract (`/r/{btoa(JSON.stringify(recipe))}`) is browser-native and unaffected by Angular version
- `ng2-sharebuttons` removed entirely — no replacement in this upgrade (Web Share API planned for future feature)
- `@angular/http` / `HttpModule` was imported but never used — simply deleted
- File naming follows Angular 2025 convention: `recipe.ts` not `recipe.component.ts`
- The scaffold provides app.ts, app.config.ts, app.routes.ts as stubs — tasks update content, not create from scratch
- [P] tasks = different files, no dependencies on incomplete tasks in the same phase
- Commit after each task or logical group
- Stop at any checkpoint to validate independently
